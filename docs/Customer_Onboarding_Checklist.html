Customer Onboarding & Go-Live Checklist

Medical-Supply ERP on Odoo 18 — taking a new customer from empty database to running the business.

How to use this: work top to bottom and tick each box. Steps 0–1 are technical (done once per customer); steps 2–13 are configuration inside Odoo. A typical 5–10 user company takes about 1–2 hours end to end. Menu paths are shown like Settings › Users.

0 Before you start — gather this from the customer

  • Legal company name, full address, phone, email, and tax / VAT ID
  • Company logo (PNG or SVG) and a square favicon
  • Base currency (SDG) and any foreign currencies they buy/sell in (USD, EUR)
  • User list — name, email, and role for each of the 5–10 people
  • Bank account details — bank name, account number, and currency for each account
  • Product / item catalogue (or a representative sample to start)
  • Warehouse / branch list and storage areas
  • Opening balances — stock on hand (with expiry), customer & vendor balances, bank balances

1 Provision the instance (one command)

  • Create a DNS A record for the subdomain (e.g. acme.yourdomain.com) pointing to the server IP
  • Run: ./scripts/new-tenant.sh acme acme.yourdomain.com admin@yourdomain.com
  • Confirm https://acme.yourdomain.com opens the login page with a valid padlock
What this does: creates the customer's own database, installs the medical-supply module set, gets the SSL certificate, and routes the subdomain to their database. Their data is fully isolated from every other customer.

2 Secure the admin account

  • Log in as admin and immediately set a strong password
  • Set language to Arabic and the correct timezone — Settings › Users › admin › Preferences
  • Confirm the database manager is hidden (list_db = False) so no one can see other databases

3 Company profile

Settings › Companies

  • Company name, logo, full address, phone, email, tax ID
  • Set base currency SDG; enable multi-currency and an exchange-rate source if they import or price in USD/EUR
  • Set the fiscal year and lock dates — Accounting › Configuration › Settings
  • Configure the document layout (letterhead, colours, footer) used on invoices & purchase orders

4 Users & access rights

Settings › Users & Companies › Users — create one per person, set language Arabic, send the invite.

RoleTypical access rights to grant
Warehouse / InventoryInventory: User or Manager
Procurement / BuyerPurchase: User or Manager
SalesSales: User; Invoicing: read
Finance / AccountantAccounting: Accountant or Adviser
Owner / ManagerSettings (Administration) — limit to 1–2 people only

5 Contacts (vendors & customers)

Contacts

  • Add vendors / suppliers with their payment terms and currency
  • Add customers (clinics, hospitals, pharmacies) with payment terms and delivery addresses
  • Tag / categorise them (e.g. Supplier, Hospital, Pharmacy) for easy filtering and reporting

6 Bank & payment setup

Accounting › Configuration › Journals / Bank Accounts

  • Add the company's bank account(s) — one per account/currency
  • Create the matching Bank journal(s); add a Cash journal if they handle cash
  • Define payment terms (e.g. Immediate, 15 days, 30 days)
  • Confirm bank reconciliation is ready (the OCA reconciliation module is installed)

7 Chart of accounts & taxes

Accounting › Configuration

  • Confirm or import the chart of accounts
  • Configure taxes (VAT rate / exempt) and set the default sale & purchase tax
  • Set default income, expense, and inventory accounts

8 Warehouses & locations

Inventory › Configuration

  • Define the warehouse(s) / branches
  • Set up internal locations (storage, quarantine, expired/damaged)
  • In Inventory Settings, enable Lots & Serial Numbers and Expiration Dates
  • Set removal strategy to FEFO (First Expiry, First Out) so near-expiry stock ships first

9 Products / items

Inventory › Products

  • Create product categories (e.g. Pharmaceuticals, Devices, Consumables)
  • Set units of measure (box, strip, vial, piece) and pack conversions
  • Create products as Storable, tracked by Lot, with expiration tracking on
  • Enter cost price, sales price, taxes, and an internal reference / barcode
  • Add reordering rules (min / max) per product and warehouse
  • Add vendor pricelists (purchase price and lead time per supplier)

10 Opening balances & initial stock

  • Stock on hand: run an Inventory Adjustment to load quantities with lot numbers and expiry dates — Inventory › Operations › Physical Inventory
  • Opening receivables/payables: enter open customer invoices & vendor bills, or a single opening journal entry
  • Opening bank/cash balances: post via journal entry and reconcile the opening statement

11 Branding

Settings › General Settings › Nile Theme

  • Upload the navbar logo and favicon; set the browser-tab name
  • Pick the colour palette; confirm Arabic / RTL layout looks right

12 Go-live verification — the "ready for business" gate

  • Run one full cycle end to end: Purchase Order → Receive (with lot & expiry) → Sales Order → Delivery → Customer Invoice → Register Payment → Reconcile
  • Check an inventory report shows correct quantities and expiry dates
  • Check an Aged Receivable / Aged Payable report is correct
  • Nightly backup scheduled (DB_NAME=acme bash scripts/backup_db.sh) + offsite copy + one test restore done
  • SSL padlock valid; only 1–2 people have Settings (admin) rights
  • Delete any demo / test records created during setup

13 Handover

  • Deliver credentials securely (password manager or sealed handover — never plain email)
  • Run a short training session per role (warehouse, buying, sales, finance)
  • Share the user manual — docs/manual (EN/AR)
