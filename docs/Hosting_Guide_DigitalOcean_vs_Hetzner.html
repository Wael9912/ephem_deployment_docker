Hosting Guide — DigitalOcean vs Hetzner

Where to host, what it costs, and how big a server you need for 5–20 medical-supply customers.

The quick verdict

Host on Hetzner. For the same (or better) hardware it costs roughly 4–5× less than DigitalOcean, and its German/Finnish data centres give good latency to Sudan. Choose DigitalOcean only if you specifically want its managed database (it handles Postgres backups and failover for you) and the most beginner-friendly control panel — and you accept paying several times more.

2 Strengths & trade-offs

Hetzner

  • 4–5× cheaper for equal/better specs
  • Dedicated AMD EPYC CPU + more disk & bandwidth included
  • EU data centres (Falkenstein, Helsinki) close to Sudan
  • Fewer global regions; plainer control panel
  • You run & back up PostgreSQL yourself
  • Email-based support (no phone)

DigitalOcean

  • Easiest console + best tutorials for non-experts
  • Managed PostgreSQL (auto backups, failover, patching)
  • Spaces (S3-style) storage for offsite backups; 1-click apps
  • More global regions
  • 3–5× the price
  • Less disk per plan; "Basic" tiers share CPU

4 How big a server do I rent?

Rule of thumb: ~3 GB RAM and ~30 GB disk per 5–10-user company. Add them up, add ~20% headroom, round up.

  • Save RAM at scale: run one shared PostgreSQL with a database per customer, while keeping a separate Odoo container per customer — cuts memory use noticeably at 15–20 tenants.
  • At 20 customers, split across two servers so one failure never takes everyone down.
  • Start small and resize up — on both hosts, growing a server is a few clicks plus a reboot.

5 Every server needs this (whichever host)

  • OS & firewall: Ubuntu 24.04 LTS; open only ports 22 (SSH, key-only), 80, 443; install fail2ban; deploy as a non-root user in the docker group.
  • Backups: nightly scripts/backup_db.sh per database (it saves the database and the uploaded files).
  • Offsite copy: sync backups off the server daily (rclone to Backblaze B2 or DigitalOcean Spaces). A backup on the same server is not a backup.
  • Restore drill: test a restore once a quarter — an untested backup is just a hope.
  • TLS: certificates auto-renew (already built into the stack).
  • Monitoring: watch memory/disk with docker stats; add an uptime check.
  • Versions: keep the pinned releases in docs/DEPLOY_PINS.md.

6 Region & latency for Sudan

Both hosts have European data centres that serve Sudan well (~80–120 ms). Pick the closest EU region:

  • Hetzner: Falkenstein / Nuremberg (Germany), Helsinki (Finland).
  • DigitalOcean: Frankfurt (Germany), Amsterdam, London.
Bottom line

For 5–20 medical-supply customers, rent a Hetzner CCX server in Frankfurt or Helsinki, size it at ~3 GB RAM + 30 GB disk per company, and turn on nightly backups with an offsite copy. You'll get dedicated CPU and save thousands per year versus DigitalOcean. Reach for DigitalOcean only if you'd rather pay a premium to have its managed database and hand-holding console do more of the work for you.
